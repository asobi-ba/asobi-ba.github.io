# ブラウザゲーム置き場

インストール不要で遊べる自作のブラウザゲームを置いています。
公開先: https://asobi-ba.github.io/

## 中身

| ゲーム | 内容 | 操作 |
|---|---|---|
| [タピオカ](tapioca/) | ミルクティーの中の避けゲー。黒い粒をぎりぎりでかすめると点の倍率が上がる。ロックBGMと効果音つき | 指でなぞる／マウス移動、右クリックか Space で一気飲み |
| [塔と井戸](tou-to-ido/) | ファミコン風ドット絵の2本立て。塔をのぼる／井戸をおりる | 塔＝クリックでジャンプのみ、井戸＝左右キー |
| [黒い轍](kuroi-wadachi/) | 夜の峠のドリフトタイムアタック。コース3本、ベストタイムはコースごとに保存 | 左右キーでハンドルのみ（アクセル自動・ブレーキ無し） |
| [速記](sokki/) | 日本語入力（かな漢字変換）のまま六十秒で何文字書けるか。初級＝単語・中級＝一文・上級＝長文の三段、記録は段ごとに保存 | 日本語入力オンのまま打って Enter、Esc でその文を飛ばす |
| [逆ハンドル](gyaku-handle/) | 大型トレーラーのバック駐車。折れ角110度でジャックナイフ、切り返して入れ直す。運転席＋左右ミラーの視点あり。エンジン音・バックブザー・エア音つき。課題3つ | 左右キーでハンドル、下キーで後退・上キーで前進 |

## つくり

- それぞれ HTML ファイル1つだけで動きます。ビルド作業や外部ライブラリはありません
- 読み込む外部のものは Google Fonts のみ
- 得点は各自のブラウザ（localStorage）にだけ保存され、どこにも送信されません
- 音は音源ファイルを使わず、Web Audio でその場で波形を作っています（どちらも画面内で切り替え可）
  - タピオカ … ハ長調168拍/分のロックBGMと効果音6種。旋律・歪ませたギター・ベース・ドラムをすべて波形から合成しています（重ねてから歪ませ、そのあとフィルタ）。音量つまみは画面左下
  - 塔と井戸 … ジャンプや被弾の効果音
  - 逆ハンドル … ディーゼルのエンジン音（6気筒4サイクルの爆発を波形で作り、回転数で再生速度を変える）、バックブザー、停車時のエア音、接触音

## 手を入れるとき

各ゲームの `index.html` を直接編集します。`main` に push すると GitHub Pages へ反映されます。
