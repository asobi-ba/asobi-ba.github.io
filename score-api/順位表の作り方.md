# 順位表の置き場をつくる（Cloudflare）

所要 15分ほど。**ここに書いてある合言葉やURLは、このファイルには書き込まないこと。**

---

## 1. D1（点数をしまう表）をつくる

1. <https://dash.cloudflare.com> を開く
2. 左の **Storage & Databases** → **D1 SQL Database**
3. **Create**
4. 名前は `game-scores` と入れて作成

表の中身（列）は**プログラムが自動で作る**ので、SQL を打つ必要はない。

---

## 2. Worker（受付係）をつくる

1. 左の **Compute (Workers)** → **Workers & Pages**
2. **Create** → **Start with Hello World!** → **Deploy**
3. 名前は `game-scores` でよい（URLが `game-scores.<自分の名前>.workers.dev` になる）
4. できたら **Edit code**（コードを編集）を押す
5. 出てきた中身を**全部消して**、このフォルダの `worker.js` の中身を**まるごと貼り付ける**
6. 右上の **Deploy**

---

## 3. 表を受付係につなぐ

1. Worker の画面 → **Settings** → **Bindings**
2. **Add binding** → 左の一覧から **D1 database** を選ぶ
3. **Variable name** に `DB` と入れる（**半角大文字2文字。この綴りでないと動かない**）
4. **D1 database** で さっき作った `game-scores` を選ぶ
5. **Add Binding**

---

## 4. 設定を2つ入れる

同じ **Settings** → **Variables and Secrets** で2つ足す。

| 名前 | 種類 | 中身 |
|---|---|---|
| `ALLOW_ORIGIN` | Text | `https://pdylplplp-stack.github.io` |
| `ADMIN_KEY` | **Secret** | 自分で決めた合言葉 |

**合言葉の決め方**

- **半角の英数字と記号だけ**にすること（日本語は通信の決まりで送れない）
- 20文字くらい。例：`kuruma-2026-xKq7Rm2p`（**この例はそのまま使わない**）
- **紙かパスワード管理ソフトに控える。このファイルやGitHubには絶対に書かない**

`ADMIN_KEY` は必ず **Secret**（Text ではなく）で入れること。Text だと画面に出たままになる。

---

## 5. 動いているか見る

ブラウザで、自分の Worker のURLを開く。

```
https://game-scores.<自分の名前>.workers.dev/
```

「順位表の預かり所です。」と出れば成功。

次にこれを開く。

```
https://game-scores.<自分の名前>.workers.dev/board?game=tapioca
```

`{"game":"tapioca",...,"list":[]}` のように出れば、棚もつながっている。
`error` と出たら、手順3の綴り（`SCORES`）を見直す。

## あとで使うこと

### 変な名前を消す

パソコンのコマンド（PowerShell）で。`<...>` は自分のものに置き換える。

```powershell
$k = Read-Host "合言葉"
Invoke-RestMethod -Method Post -Uri "https://game-scores.<自分の名前>.workers.dev/admin/remove" `
  -Headers @{ "x-admin-key" = $k } `
  -ContentType "application/json; charset=utf-8" `
  -Body ([Text.Encoding]::UTF8.GetBytes('{"game":"tapioca","name":"消したい名前"}'))
```

### そのゲームを空にする

上の `/admin/remove` を `/admin/clear` に変え、`Body` を `'{"game":"tapioca"}'` にする。

## 無料枠（2026年9月時点の公式値）

| | 無料枠 | 今回の使い方 |
|---|---|---|
| Worker の呼び出し | 100,000回/日 | 1回遊ぶと2〜3回 |
| D1 の読み取り | **500万行/日** | 順位表を見るたび20行ほど |
| D1 の書き込み | **100,000行/日** | 点数を出すたび1行 |
| D1 の保存容量 | 5GB | 1ゲーム数KB |

出典: [Workers の制限](https://developers.cloudflare.com/workers/platform/limits/) ／ [D1 の料金](https://developers.cloudflare.com/d1/platform/pricing/)

### なぜ KV ではなく D1 か

KV は書いた内容が世界中に行き渡るまで最大60秒ほどかかる。そのため
**二人がほぼ同時に点数を出すと、古い内容を読んで上書きし、片方が消える**
ことが原理上ありえる。D1 は書いた内容がすぐ確実に反映されるので、
順位表にはこちらが向く。書き込みの枠も100倍ある。

---

## 分かっている弱点（直せないもの）

- **点数の偽装は防げない。**公開サイトから送る以上、誰でも好きな数字を送れる。上限を超える値は弾くが、それ以上は止められない
- **名前は自由に書ける。**目に余る語句のふるいは入れてあるが、網であって完全ではない。出たら上の手順で消す
- **遊んだ人のIPアドレスは Cloudflare のサーバーに届く**（どんなサービスでも同じ）。こちらでは保存しない
